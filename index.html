The EDG open source transition

EDG is going open source.

On September 30, 2026, the source for EDG's C++ front end goes public, and The C++ Alliance becomes its nonprofit home. Same engine, same standards, professionally maintained.

Follow along on GitHub Read the plan

Continuity is the point. This is a change of steward, not a change of course.

Why The C++ Alliance

The C++ Alliance is a nonprofit with proven fiscal-sponsorship infrastructure, C++ compiler engineers on staff, and deep roots in the C++ standards and Boost communities. It will serve as EDG's nonprofit home.

Learn more about The C++ Alliance

  • Fiscal sponsor of the Boost C++ Libraries since 2024
  • LLVM committers with direct Clang front-end contributions
  • A former LWG Chair and libc++ code owner on staff
  • Published transparency reports

How it works

Two tracks, one codebase, no early access

Development is funded on two tracks. Both end in the same place: code that everyone gets at the same time.

Track 1

Bug fixes: always open

Fixes are published immediately. No gating, no delays.

Track 2

Features: collectively funded

Users collectively fund new development. Once a feature is funded, it is released to everyone simultaneously.

No one gets early access. Not donors, not the Alliance, not anyone.

What this means for you
